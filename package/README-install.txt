DroidVM GPU driver — НЕОФИЦИАЛЬНАЯ сборка
==========================================

Это неофициальная сборка драйвера VirtIO-GPU для Windows 11 ARM64 в DroidVM.
Авторы драйвера: anonymix007 и команда DroidVM (https://github.com/Droid-VM).
Сборка сделана автоматически из открытых исходников, лицензия GNU AGPL-3.0.
Распространяется бесплатно, НЕ ДЛЯ ПРОДАЖИ. Без каких-либо гарантий.

ПЕРЕД УСТАНОВКОЙ сделайте клон (резервную копию) диска виртуальной машины.

Установщик:
  1. добавит тестовый сертификат в «Доверенные корневые» и «Доверенные издатели»;
  2. включит режим тестовой подписи (bcdedit /set testsigning on);
  3. установит драйвер через pnputil;
  4. попросит перезагрузку.

Откат: «Параметры → Приложения → DroidVM GPU driver → Удалить»
или DroidVM-GPU-Uninstall.exe. Журналы: C:\ProgramData\DroidVM-GPU\
